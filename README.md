# API Development and Database Normalization

A RESTful API built with Express, TypeScript, and MySQL for managing an e-shop product catalog. The project demonstrates a normalized database design (3NF) with a many-to-many relationship between products and categories, implemented through a junction table.

## Features
- Full CRUD operations for products and categories
- Many-to-many relationship between products and categories via a junction table
- Search and sorting support on both resources
- Input validation and error handling
- Type-safe models using TypeScript classes
